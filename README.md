# LIAR ROYALE — 라이어 로얄

각자의 휴대폰에서 같은 주소로 접속해 4자리 코드로 참여하는 실시간 라이어게임입니다. 최대 15명, 최소 3명.

## 실행

Node.js 18 이상 설치 후 폴더에서 `node server.js` 실행하고 `http://localhost:3000`으로 접속하세요. 같은 와이파이의 휴대폰은 컴퓨터의 내부 IP 주소를 사용해 `http://컴퓨터IP:3000`으로 접속할 수 있습니다. 다른 네트워크의 친구까지 접속하려면 서버를 인터넷에 공개 배포하고 HTTPS 주소로 접속해야 합니다. 방 코드만으로 외부 네트워크를 직접 연결할 수는 없습니다.

## 사용법

방장이 닉네임을 입력하고 방 만들기 → 4자리 코드/초대 링크 공유 → 친구가 각자 입장(3~15명) → 방장 게임 시작 → 각자 비밀 카드 확인 → 전원 확인 완료 시 토론 시작 → 타이머 종료 시 투표 → 라이어 최종 추측(라이어 적발 시) → 결과 및 누적 점수 → 다음 라운드.

## 주의

현재는 간단한 파티게임 시범 버전입니다. 방은 서버 메모리에 저장되므로 서버를 재시작하면 소멸합니다. 접속 인증은 브라우저 탭별 임시 토큰이며 대규모 공개 서비스용 보안 인증이 아닙니다. 4자리 방 코드는 편리하지만 추측 가능하므로 비공개 게임에만 사용하세요. 초대 링크 복사는 일부 모바일 HTTP 환경에서 브라우저 보안 정책으로 차단될 수 있으므로 코드 직접 공유를 이용하세요.

### 제시어 중복 방지
- 제시어 40개를 모두 사용하기 전에는 다음 라운드와 새 방에서 재사용하지 않습니다.
- 실시간 서버는 `used-words.json` 파일에 공용 사용 기록을 저장합니다. 서버가 영구 저장소 없이 재설치되는 경우에는 기록이 초기화될 수 있습니다.
- 체험 미리보기는 해당 브라우저의 `localStorage`에 사용 기록을 유지합니다. 브라우저 데이터 삭제/다른 기기에서는 기록을 공유하지 않습니다.
- 40개를 모두 사용한 뒤에만 목록을 다시 시작하며, 직전 제시어와 바로 중복되지 않습니다.

## GitHub + Render 배포
1. GitHub에서 `liar-royale-15`라는 새 공개 저장소를 생성합니다 (README 자동 생성 안 함).
2. 이 폴더의 파일 5개 (`index.html`, `server.js`, `package.json`, `render.yaml`, `README.md` 및 `.gitignore`)를 저장소 최상위에 업로드합니다.
3. Render에서 **New > Web Service**를 선택해 GitHub 저장소를 연결합니다. Node 런타임, `npm install` 빌드, `npm start` 실행, Singapore 지역으로 설정합니다.
4. 배포 상태가 Live가 되면 Render의 `https://...onrender.com` 주소를 친구들에게 공유합니다.

GitHub Pages는 서버 기능을 실행하지 못하므로 실시간 방 만들기에는 적합하지 않습니다. 무료 Render 서비스는 유휴 상태 시 잠들 수 있으며 파일 시스템이 영구 저장되지 않을 수 있습니다. 제시어 사용 기록도 서버 재생성 시 소실될 수 있습니다. 지속적인 중복 방지에는 영구 DB/디스크 연결이 필요합니다.
